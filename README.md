## 🚀 Getting Started

### 1. Install Python

Download and install Python from the official Python website.

### 2. Clone this Repository

```bash
git clone https://github.com/amitbaldaniya73-ops/Python.git
```

### 3. Open the Project

```bash
cd Python
```

### 4. Run a Python Program

```bash
python filename.py
```

Example:

```bash
python "fibonacci series.py"
```
