
# Manager Management System

## 📌 Project Description

This is a Python-based Manager Management System.
It allows users to create and manage manager details
through a simple menu-driven program.

## 🚀 Features

1. Create a manager
2. Display manager details
3. Update manager details
4. Delete a manager
5. Exit

## 🛠️ Technologies Used

- Python
- Functions
- Loops
- Conditional Statements
- User Input

## 📋 Main Menu

```text
-----------------------------------------
        Manager Management System
-----------------------------------------

1. Display Manager
2. Update Manager
3. Create a manager
4. Delete Manager
5. Exit

Enter your choice:
```

## ▶️ How to Run

1. Install Python on your computer.
2. Open VS Code or Python IDLE.
3. Create a Python file.
4. Run the program.

```bash
python manager.py
```
